# Build AI Research Assistant

This is a simple command-line research tool with two useful modes:

1. Research a company using live web search results.
2. Ask questions about your own PDF documents.

The answers are generated by Gemini, but the application first gathers useful information and gives it to the model. This helps keep the answers focused on real sources and document content.

## What it can do

### Company research

Enter a company name and the app will:

- Search the web with Tavily.
- Send the search results to Gemini.
- Create a structured report with the industry, summary, products or services, business model, competitors, advantages, opportunities, and risks.
- Show the web sources used in the report.

### Ask questions about a PDF

The app also includes a small RAG (Retrieval-Augmented Generation) workflow. In simple terms, it finds the most relevant parts of a PDF before asking Gemini to answer a question.

The workflow is:

1. Read the PDF page by page.
2. Split each page into smaller overlapping text chunks.
3. Convert each chunk into a numerical embedding using `all-MiniLM-L6-v2`.
4. Save the chunks and embeddings in `data/index.json`.
5. Convert the user's question into an embedding.
6. Find the five closest chunks using cosine similarity.
7. Ask Gemini to answer using only those chunks.

The answer also shows the retrieved source file and page number, so you can check where the information came from.

## Project structure

| File | Purpose |
| --- | --- |
| `app/main.py` | Main menu, company research, and document question answering |
| `app/search.py` | Searches the web with Tavily |
| `app/prompts.py` | Prompts for company research and document questions |
| `app/schemas.py` | Validates research reports and source links with Pydantic |
| `app/document_loader.py` | Extracts text from PDF files |
| `app/chunker.py` | Splits page text into overlapping chunks |
| `app/embeddings.py` | Creates embeddings with Sentence Transformers |
| `app/indexer.py` | Builds and loads the saved document index |
| `app/vector_store.py` | Calculates similarity and retrieves relevant chunks |
| `app/test_retrieval.py` | Prints the most relevant chunks for a test question |

## Requirements

- Python 3.10 or newer is recommended.
- A Gemini API key for generating reports and answers.
- A Tavily API key for web search.
- A PDF document when using document questions.

Install the packages from `requirements.txt`:

```powershell
python -m pip install -r requirements.txt
```

## Setup

Create and activate a virtual environment:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Create a `.env` file in the project root:

```env
GEMINI_API_KEY=your_gemini_api_key
TAVILY_API_KEY=your_tavily_api_key
```

Keep `.env` private. Do not commit API keys to GitHub.

## Prepare a PDF index

Put a PDF inside a `documents` folder. The current example code expects this file:

```text
documents/tcs-annual-report-2025-2026.pdf
```

To build the searchable index, run:

```powershell
python -m app.indexer
```

This creates `data/index.json`. The index is needed before using document question answering.

## Run the assistant

Start the interactive application:

```powershell
python -m app.main
```

Choose an option from the menu:

- `1` researches a company.
- `2` answers a question using the indexed PDF.
- `3` exits the program.

## Test document retrieval

To see which five chunks are found for a question without asking Gemini for a final answer:

```powershell
python -m app.test_retrieval
```

## Important notes

- Company research depends on both `GEMINI_API_KEY` and `TAVILY_API_KEY`.
- Document questions need an existing `data/index.json` file.
- The first use of Sentence Transformers may download the `all-MiniLM-L6-v2` model.
- The application asks Gemini not to guess and to use only the provided web sources or document context.
- The current implementation uses the `gemini-3-flash-preview` model for generated answers.
